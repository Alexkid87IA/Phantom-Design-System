# UI Kit · Marketing

Landing complète Phantom — direction **Néo Pop** dominante + nav glass dock issue de Spectre.

## Fichiers

- `index.html` — point d'entrée, mount React, charge tous les composants
- `components.jsx` — atomes partagés : `<Logo />`, `<GhostMark />`, `<Button />`, `<Tag />`, `<PopCard />`, `<Eyebrow />`
- `Nav.jsx` — pastille flottante de navigation
- `Hero.jsx` — hero principal (type magazine + posters de droite)
- `Services.jsx` — grille des 6 catégories d'agents
- `CaseStudy.jsx` — preuves sociales (résultats + témoignages)
- `Pricing.jsx` — 3 plans (Solo, PME, Sur-mesure)
- `Manifesto.jsx` — section éditoriale longue
- `Footer.jsx` — éditorial avec gros mots

## Sections couvertes

1. Nav flottante (Spectre / Lolo-inspired)
2. Hero — punchline + 2 posters preuves
3. Tags des catégories d'agents (rainbow)
4. Manifesto éditorial — "On gère."
5. Services — 6 cards d'agents
6. Case study — Sushi Boy avant/après
7. Pricing
8. Footer mega-type

## Vocabulaire visuel

- Hero type display 120px Space Grotesk
- Pop cards avec bordure 2px noir + offset shadow
- Rainbow accents pour chaque agent
- Mascotte qui peek hors des cartes
- Sections rythmées (blanc / violet / jaune)

## Tone of voice

FR, tutoiement, direct. "On gère.", "Crée ton agent en 3 minutes", "L'IA bosse, toi tu dors."
