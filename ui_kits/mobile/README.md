# UI Kit · Mobile

App mobile Phantom — iOS frame avec 3 écrans-clés montrés côte à côte.

## Écrans

- `OnboardingScreen.jsx` — bienvenue, choix d'agent
- `HomeScreen.jsx` — dashboard mobile (KPIs + agents + activité)
- `ChatScreen.jsx` — conversation avec un agent

## Fichiers

- `components.jsx` — Ghost, Tag, Bar, IconRound
- `ios-frame.jsx` — starter iOS 26
- `index.html` — affiche les 3 phones en parallèle

## Notes

- Largeur natif iOS = 402px
- Tap targets ≥ 44px
- Pas de hover states (mobile)
- Animations float pour la mascotte de la home
