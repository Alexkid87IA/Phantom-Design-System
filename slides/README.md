# Slides — Deck commercial Phantom

Deck de présentation commerciale en 8 slides, esthétique **Néo Pop** (direction A).

Format : 1920×1080 (16:9). Géré par `deck-stage.js` — touches fléchées / espace / clic pour naviguer, "P" pour PDF.

## Sommaire

1. **Titre** — punchline + mascotte
2. **Problème** — la galère des TPE/PME en ligne
3. **Manifeste** — Phantom = équipe + agents
4. **Catalogue** — les 6 agents
5. **Méthode** — 3 étapes
6. **Cas client** — Sushi Boy avant/après
7. **Tarifs** — 3 plans
8. **Closing** — "On se parle ?" + contact

## Fichiers

- `index.html` — le deck complet en static HTML (directement éditable par l'utilisateur)
- `deck-stage.js` — moteur du deck

## Tone

Punchy, FR, tutoiement, on assume l'irrévérence ("Toi tu dors", "On gère").
